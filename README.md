### 🏦 Bank Support Chatbot — NLP & RAG

A web-based chatbot for commercial bank customer support using NLP technologies.

**Technologies:**
`Python` `PyTorch` `Transformers` `RAG` `FAISS` `Sentence Transformers` `scikit-learn` `FastAPI`

**Implemented:**

* Encoder-Decoder Transformer
* RAG pipeline
* Semantic document retrieval with FAISS
* Sentence embeddings
* Topic classification with Logistic Regression
* FastAPI backend
* Model evaluation using Token F1, BLEU and ROUGE-L

The RAG-based approach significantly improved the quality of generated answers compared with the standalone Transformer model.
